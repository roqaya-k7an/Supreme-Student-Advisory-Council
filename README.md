## 📖 Overview

This is the online home of the Supreme Student Advisory Council at IIUI — a
responsive, fully **bilingual** web app where students can learn about the
Council, register, and take part in competitions and activities. The interface
works seamlessly in both **English** and **Arabic (العربية)**, with complete
right-to-left (RTL) support, and adapts cleanly to phones, tablets, and desktops.

---

## ✨ Features

- 🌍 **Bilingual UI** — instant English ⇄ Arabic switching with full RTL layout.
- 📝 **Student registration** — a simple, validated sign-up flow.
- 🏆 **Competitions & activities** — browse events and register online.
- 🔐 **Secure admin dashboard** — manage members and view submissions.
- 📱 **Responsive design** — a consistent experience on any screen size.
- 🎨 **Branded interface** — built around the Council's visual identity.
